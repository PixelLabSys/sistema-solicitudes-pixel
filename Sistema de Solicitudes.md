# Sistema de Solicitudes  
  
Requerimos crear un nuevo sistemas de Permisos donde tenemos.  
  
Solicitud de Permisos  
Solicitud de Vacaciones  
Solicitud de Adelantos de Nómina  
  
La trazabilidad de estos sistemas es el siguiente:  
  
Cualquier colaborador puede pedir una de estas solicitudes. Llena el Formulario. Este formulario le llega a su líder directo. Este líder directo aprueba o no. Esta aprobación viaja como notificación al solicitante con la respuesta y de ser aprobado llega al líder de Talento humano.  
  
  
Se entrega una lista de colaboradores (Nombre y Correo)  
  
Todos los Colaboradores pueden hacer solicitudes.  
  
Algunos de esos colaboradores pueden ser elegidos adicionalmente como Líderes (de área)  
  
Alguno de esos colaboradores puede ser Líder de Talento Humano  
  
Ejemplo: Pueden ser 25 colaboradores, de ellos pueden haber 4 líderes y 1 de ellos puede ser líder de Talento humano.  

Cada caso o solicitud tiene un consecutiv diferente... Puede ser un Código para cada tipo de Solicitud. Ejemplo: SP 0001 - SV 0001 - SN 0001 para su fácil identificación
